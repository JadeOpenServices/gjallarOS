Getting started with Thunderbird

This page is stored on your computer and loads nothing from the internet. To stop showing it, untick "When Thunderbird launches, show the Start Page" under Settings, General.

1. Add your mail account

Choose the menu, then New, then Existing Mail Account. Enter your name, address and password. Thunderbird asks your mail provider for the server settings, over HTTPS only. If it finds nothing, ask your provider for the IMAP and SMTP settings and enter them by hand.

2. Set a Primary Password

Thunderbird asks for one before it saves your first account password. It protects your saved passwords, login tokens and encryption keys. Without it, anyone with a copy of your home folder could read them.

  • Pick a long passphrase you do not use anywhere else, and save it in your password manager.
  • Thunderbird asks for it once after each start. It cannot be removed again.
  • If you forget it, the saved passwords and keys are lost. Keep the key backup from step 4.

3. Create or import your OpenPGP key

Open Account Settings, then End-To-End Encryption, then Add Key. Create a new key, or import the one you already use. For a new key, choose a date it expires; you can extend it later.

4. Back up your key

In the OpenPGP Key Manager, select your key, then File, then Backup Secret Key(s) To File. Thunderbird asks for a password for the file. Keep the file and that password in your password manager, or on a USB stick you store safely at home. Without a backup, mail encrypted to you cannot be read once the key is gone.

5. Find the keys of people you write to

Thunderbird searches key servers only when you ask: "Discover Public Keys Online" in the key assistant, or "Discover Keys Online" in the OpenPGP Key Manager. Each search tells the key server whose key you are looking for, so it is never done in the background. You can also import a key someone sends you as a file.

6. Calendar and contacts from Nextcloud

Calendar: New Calendar, then On the Network, then enter your Nextcloud address and user name. Contacts: in the Address Book, New Address Book, then Add CardDAV Address Book, with the same address. Use an app password from Nextcloud (Settings, Security), not your main password.

How mail is shown

  • Remote content (pictures and other files a mail loads from the internet) is blocked. Allow it per sender from the bar above the mail.
  • Mail is shown as simple HTML: layout stays, risky parts are left out. View, then Message Body As, switches to plain text or the original HTML.
  • Thunderbird warns about mails that look like scams.

What the Primary Password does not cover

While Thunderbird is open and unlocked, another program running as you can use the unlocked keys. A smart card keeps the secret key off the computer entirely. To use one, run gjallarctl settings set thunderbirdSmartCard=true, then gjallarctl settings apply, and approve the card reader when GjallarOS asks about the new USB device. In Thunderbird, choose Add Key, then Use your external key through GnuPG, and enter the key ID from the card.
